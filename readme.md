---

## 📌 Overview

**IDIP (Indian Disaster Intelligence Platform)** is a data-driven disaster analysis and visualization platform designed to understand, analyze, and communicate disaster patterns across India.

The platform combines historical disaster datasets, geospatial boundaries, and analytical intelligence to provide a unified view of disaster behavior across states.

IDIP focuses on converting raw disaster records into actionable insights through:

- Interactive geospatial visualization
- Disaster-specific intelligence dashboards
- Historical trend analysis
- State-level disaster profiling
- Data-driven decision support

---

# 🎯 Objectives

The primary objectives of IDIP are:

- Build a centralized disaster intelligence system for India
- Analyze historical disaster occurrence patterns
- Visualize disaster distribution geographically
- Provide state-wise disaster intelligence
- Compare disaster characteristics through analytics
- Create a foundation for future prediction and early-warning systems

# 🚀 Key Features

## 🗺️ Interactive India Disaster Map

IDIP provides an interactive geospatial interface for exploring disaster intelligence across Indian states.

Features:

- State-level visualization
- GeoJSON-based mapping
- Disaster-focused geographic analysis
- Interactive state selection


---

# 🌎 Disaster Intelligence Modules

## 🌍 Earthquake Intelligence

Analyzes earthquake-related historical records.

Includes:

- Total earthquake events
- Average magnitude
- Maximum magnitude
- Most active year
- Event frequency trends
- Magnitude variation trends


---

## 🌊 Flood Intelligence

Provides flood event analysis based on historical records.

Includes:

- Total flood events
- Average flood duration
- Maximum flood duration
- Fatality information
- Flood frequency trends
- Duration analysis


---

## 🌀 Cyclone Intelligence

Analyzes cyclone characteristics and historical behavior.

Includes:

- Total cyclone events
- Average wind speed
- Maximum wind speed
- Minimum pressure analysis
- Cyclone frequency trends
- Wind speed trends


---

# 📊 Disaster Analytics Dashboard

The graph intelligence dashboard provides visual analysis of disaster patterns.

Current visualization capabilities:

- Historical event trends
- Year-based filtering
- Disaster-specific analytics
- Comparative intelligence summaries

Visualization stack:

- Plotly
- Streamlit charts
- Custom dark-theme dashboard UI
